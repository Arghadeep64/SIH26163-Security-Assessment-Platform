03 Assessment Methodology

The assessment methodology adheres strictly to defensive security testing guidelines documented in the platform specification:

  1. Target Authorization: Strict target verification enforcing loopback or authorized staging endpoints.
  2. Safe Discovery: Non-destructive probes bounded to safe HTTP methods.
  3. Security Checks: 14 evaluation modules covering transport, headers, cookies, CORS, disclosure, and sinks.
  4. Evidence Collection: Automated redaction of tokens and credentials prior to storage.
  5. Finding Classification: Standardized classification into PASS, OBSERVATION, POTENTIAL ISSUE, CONFIRMED, and MANUAL VERIFICATION.
  6. Severity Scoring: Conservative classification without speculative scoring.
  7. Remediation Guidance: Actionable hardening recommendations for each detected weakness.
  8. Relational Persistence: Complete audit trail stored in MySQL/TiDB database tables.
